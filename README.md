🍽 Recipe Finder App – Description

Recipe Finder is a simple web-based application developed using HTML, CSS, and JavaScript. The application allows users to enter the name of a recipe and instantly view its ingredients and preparation steps.

The system uses JavaScript to check the user’s input and dynamically display the corresponding recipe details on the webpage. Ingredients are displayed using an unordered list, and preparation steps are shown using an ordered list.

This project demonstrates basic front-end development concepts such as:

DOM manipulation

Conditional statements

User input handling

Dynamic content display

The application is simple, interactive, and beginner-friendly. It serves as a mini project to understand how web applications respond to user input without requiring a backend or database.

🔑 Key Features

User can type a recipe name.

App shows ingredients.

App shows preparation steps.

Simple and easy to use.

Built using HTML, CSS, and JavaScript.

🔄 Workflow

User opens the app.

User enters recipe name.

User clicks search button.

App checks the name.

If recipe exists → shows ingredients and steps.

If not → shows “Recipe not found”.
